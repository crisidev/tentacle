Tentacle

Runs Jellyfin's ffmpeg jobs on worker nodes ("tentacles") and, as set under Settings, on the Jellyfin server itself.

Nodes

Where ffmpeg runs: the Jellyfin server and its tentacles. A tentacle gets a job only after proving it shares the directories that job uses, runs the same ffmpeg and, for hardware encoding, passes a GPU self-test.

                            Scheduling

Trickplay and audio analysis run on tentacles with this nice value: 0 is normal, 19 the lowest, so playback always comes first.

                            

                            

                                
                                
                                

                            

                            

                            

                                
                                
                                
A transcode uses 1 slot, subtitle extraction 0.25, trickplay and analysis 0.5 (at most half the slots).

                            

                            

                                
                                
                                
Compared with each tentacle's TENTACLE_WEIGHT (default 1): at 2 this server carries twice the load of a weight-1 tentacle before that tentacle is preferred; at 0.5, half.

                            

                            

                            

                                
                                
A different major or minor version is always refused. A different patch version only marks the tentacle degraded unless this is on. next check

                            Directories ffmpeg uses
                            
Taken from Jellyfin's settings and your libraries; nothing to create. Each tentacle proves it sees them at the same path as this server. A job only goes to a tentacle that shares every directory it uses.

                            Token
                            
    
                                The token comes from TENTACLE_TOKEN in the server's environment, so it is managed where you deploy Jellyfin, not here.
                                To rotate it, set the new value as TENTACLE_TOKEN and the old one as TENTACLE_PREVIOUS_TOKEN, restart Jellyfin, give the tentacles the new token, then remove TENTACLE_PREVIOUS_TOKEN.
                                
                            
    
                            
    
                                
    Tentacles authenticate with this token (TENTACLE_TOKEN or TENTACLE_TOKEN_FILE). Changing it here disconnects tentacles still using the old one.
    
                                
    
                                    
                                    
                                
    
                                
    
                                    
    
                                        
                                        
                                    
    
                                    
                                
    
                                
    Replaces the token now and keeps accepting the old one for the hours above, so you can update each tentacle. Tentacles still on the old token are marked and then disconnected when the time is up.
